# Introduction to Neural Networks: A Simple Neural Network for Digit Recognition

| Year | Event |
| --- | --- |
| 2023 | McNair Junior Fellows |

**Researcher:** Noah Robertson

## Research overview

An introduction to neural networks through a simple digit-recognition model trained on the MNIST handwritten-digit dataset. The project explores network architecture, stochastic gradient descent, and backpropagation; the implemented Go model achieved 80% accuracy.
