# Karakchi Research

**Embedded Security · Hardware Assurance · Intelligent Systems**  
University of South Carolina · Advised by Dr. Rasha Karakchi

> Student-led research combining hardware-aware security, machine learning, and cryptographic resilience.

## Research focus

| Area | Focus |
|---|---|
| Embedded security | FPGA, PYNQ SoC, secure boot, bitstream integrity, and hardware-Trojan detection. |
| AI for cyber defense | Real-time anomaly and malware detection. |
| Cryptography & quantum security | Side-channel resilience, AES monitoring, and QKD anomaly detection. |
